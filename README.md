# ITMO Modern AI Labs

Лабораторные работы по дисциплине «Современные методы искусственного интеллекта».

## Структура

- `labs/lab01/` - первая практическая работа: классические методы машинного обучения и Transfer Learning.

Каждая следующая работа добавляется отдельной папкой: `labs/lab02/`, `labs/lab03/` и т.д.

## Лабораторная работа 1

В `labs/lab01/` находятся:

- `tasks/` - девять самостоятельных Python-программ;
- `data/` - исходные данные;
- `results/` - текстовые результаты запуска;
- `screenshots/` - графики, матрицы ошибок и консольные снимки;
- `report/` - оформленный отчёт;
- `utilities.py` - вспомогательная функция визуализации.

## Запуск

```powershell
python labs/lab01/tasks/01_preprocessing.py
```

Пункт 9 использует `torch` и `torchvision` для эксперимента Transfer Learning.
